# XB Admin — لوحة إدارة أكواد التفعيل

مشروع بداية قابل للنشر لإدارة أكواد تفعيل **منتجك أو خدمتك أنت**. لا يتصل بأنظمة 1xBet الداخلية ولا يمنح صلاحيات في منصات طرف ثالث.

## المزايا
- لوحة عربية متجاوبة واتجاه RTL.
- دخول مسؤول بكلمة مرور مجزأة باستخدام bcrypt.
- جلسة JWT داخل Cookie من نوع HttpOnly وSameSite=Strict.
- إنشاء أكواد عشوائية، وتحديد عدد مرات الاستخدام وتاريخ الانتهاء.
- تخزين بصمة SHA-256 للكود بدل النص الكامل.
- عرض إحصائيات، وترقيم صفحات، وإلغاء الأكواد.
- PostgreSQL، والتحقق من المدخلات، وتحديد معدل الطلبات، ورؤوس Helmet.
- مسار تفعيل عام `POST /api/activate` لمستخدمين في تطبيقك.

## المتطلبات
- Node.js 20 أو أحدث
- PostgreSQL 14 أو أحدث
- استضافة تدعم Node.js وHTTPS ومتغيرات البيئة

## تشغيل محلي
1. ثبّت Node.js وPostgreSQL.
2. انسخ `.env.example` إلى `.env`، وعدّل `DATABASE_URL` و`JWT_SECRET` وبيانات المسؤول. اجعل سر JWT عشوائيًا وطويلًا (32 حرفًا على الأقل)، ولا ترفع `.env` إلى Git.
3. ثبّت الحزم:
   ```bash
   npm install
   ```
4. أنشئ الجداول وعميل Prisma:
   ```bash
   npx prisma generate
   npx prisma db push
   ```
5. أنشئ حساب المسؤول:
   ```bash
   npm run admin:create
   ```
   كلمة المرور المطلوبة لا تقل عن 14 حرفًا.
6. شغّل التطبيق:
   ```bash
   npm start
   ```
7. افتح `http://localhost:3000`.

## النشر على الإنترنت
1. أنشئ قاعدة PostgreSQL مُدارة على مزود موثوق، واحتفظ بعنوان الاتصال في `DATABASE_URL`.
2. أنشئ خدمة Node.js من مستودع المشروع.
3. اضبط متغيرات البيئة في لوحة الاستضافة: `NODE_ENV=production`، و`DATABASE_URL`، و`JWT_SECRET`، و`ADMIN_EMAIL`، و`ADMIN_PASSWORD`، و`APP_ORIGIN=https://your-domain.example`.
4. أمر البناء/الإعداد: `npm ci && npx prisma generate && npx prisma db push`.
5. أمر التشغيل: `npm start`. شغّل `npm run admin:create` مرة واحدة بعد ضبط المتغيرات لإنشاء المسؤول.
6. اربط نطاقًا وفعّل HTTPS. اختبر `/api/health` ثم تسجيل الدخول وإصدار كود وإلغاءه.
7. للإنتاج المؤسسي، استخدم migrations مُراجعة بدل `db push`، ونسخًا احتياطية، ومراقبة، وتنبيهات، وسياسة تدوير للأسرار.

## واجهات API
- `POST /api/auth/login` — `{ "email": "...", "password": "..." }`
- `POST /api/auth/logout`
- `GET /api/auth/me`
- `GET /api/admin/stats` — يتطلب دخول مسؤول
- `GET /api/admin/codes?page=1&limit=25` — يتطلب دخول مسؤول
- `POST /api/admin/codes` — `{ "label": "تجريبي", "maxUses": 1, "expiresAt": "2027-01-01T00:00:00.000Z" }`، و`expiresAt` اختياري
- `POST /api/admin/codes/:id/revoke` — يتطلب دخول مسؤول
- `POST /api/activate` — `{ "code": "XB-...", "subject": "user-123" }`

## ملاحظات أمنية قبل الإنتاج
- الكود الكامل يُعرض مرة واحدة فقط؛ خزّنه في مكان آمن عند إنشائه.
- `subject` في مسار التفعيل مجرد معرّف يرسله العميل في هذه النسخة الأولية. قبل ربطه بمنتج حقيقي، اربطه بهوية مستخدم موثّقة من نظام تسجيل دخولك، وإلا يمكن انتحال المعرّفات.
- أضف حماية CSRF ملائمة إذا غيّرت سياسة الكوكي أو استخدمت عمليات حساسة من نطاقات أخرى. لا تفعّل CORS مفتوحًا.
- راجع سياسة الخصوصية، والاحتفاظ بالسجلات، والنسخ الاحتياطي، وحدود الطلبات بما يناسب الاستخدام.
- هذا المشروع لم يُنشر تلقائيًا؛ النشر يحتاج حساب استضافة وقاعدة بيانات ونطاقًا وإعداد الأسرار.
